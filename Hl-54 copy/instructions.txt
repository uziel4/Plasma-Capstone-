### HL-54 Relay Board Interface Configuration

The Plasma Reactor Monitoring and Supervisory Control System utilizes an HL-54 relay board as the hardware switching interface between the Raspberry Pi controller and the external vacuum system components. The relay board is controlled directly through Raspberry Pi GPIO outputs and does not utilize I2C communication.

The relay board contains two separate connection sections:

1. Control Interface (GPIO Inputs)
2. Power Switching Interface (Relay Contacts)

#### GPIO Control Interface

The control interface consists of the following terminals:

* VCC
* GND
* IN1
* IN2
* IN3
* IN4
* IN5
* IN6
* IN7
* IN8

The Raspberry Pi controls each relay through the corresponding IN terminal. For the current implementation, only two relay channels are utilized.

| Raspberry Pi GPIO | Physical Pin | Relay Input | Assigned Device                 |
| ----------------- | ------------ | ----------- | ------------------------------- |
| GPIO 17           | Pin 11       | IN1         | Mechanical Roughing Pump        |
| GPIO 22           | Pin 15       | IN3         | Gas Mass Control Solenoid Valve |
| 5V                | Pin 4        | VCC         | Relay Board Power               |
| GND               | Pin 6        | GND         | Common Ground                   |

#### Relay Power Contacts

Each relay channel contains three switching terminals:

* NO (Normally Open)
* COM (Common)
* NC (Normally Closed)

The Normally Open (NO) configuration shall be used for all controlled devices. This configuration ensures that external equipment remains de-energized when the relay is inactive.

When the relay is activated by the Raspberry Pi GPIO signal, the COM and NO contacts become electrically connected, allowing power to reach the connected device.

#### Roughing Pump Wiring

The Mechanical Roughing Pump is assigned to relay channel IN1.

The corresponding power contacts are:

* COM1
* NO1
* NC1

The wiring configuration shall be:

Power Source → COM1

NO1 → Roughing Pump Power Input

Pump Return/Neutral → Direct Power Return

When GPIO17 activates IN1, Relay Channel 1 closes the connection between COM1 and NO1, energizing the pump.

#### Gas Mass Control Solenoid Valve Wiring

The Gas Mass Control Solenoid Valve is assigned to relay channel IN3.

The corresponding power contacts are:

* COM3
* NO3
* NC3

The wiring configuration shall be:

Power Supply Positive → COM3

NO3 → Solenoid Valve Positive Input

Valve Negative Terminal → Power Supply Negative

When GPIO22 activates IN3, Relay Channel 3 closes the connection between COM3 and NO3, energizing the solenoid valve.

#### Current Relay Assignment Summary

| Relay Input | GPIO   | Relay Contacts | Device                          |
| ----------- | ------ | -------------- | ------------------------------- |
| IN1         | GPIO17 | COM1 / NO1     | Mechanical Roughing Pump        |
| IN3         | GPIO22 | COM3 / NO3     | Gas Mass Control Solenoid Valve |

The remaining relay channels are reserved for future implementation of additional subsystems including turbomolecular pump control, high-voltage interlocks, gas handling equipment, and auxiliary reactor components.
